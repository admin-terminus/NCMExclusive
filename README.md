# NCMExclusive — 网易云音乐 PC 版 WASAPI 独占模式插件

让 Windows 版网易云音乐通过类似 foobar2000 的 **WASAPI 独占模式** 输出，绕过 Windows 共享混音器。是否保持源采样率/位深取决于网易云解码格式、客户端音效和声卡驱动；PCM 转换回退不属于 Bit-Perfect。

## 原理

网易云 PC 客户端原生播放器会请求 WASAPI **共享模式**。托盘只检测 `cloudmusic.exe`，通过 `CreateRemoteThread + LoadLibraryW` 定向加载 DLL；不建立全局钩子，也不向其他应用或系统服务注入。DLL 包装设备枚举器、设备和 `IAudioClient/2/3`，为播放器提供共享语义的**软件音频终端**。播放器把 PCM 写入软件队列，独立泵线程再把数据写入真正的 WASAPI 独占流；网易云事件与物理独占事件分离，避免共享调度逻辑与独占缓冲冲突。设备不支持时会尝试原格式独占、兼容 PCM 独占，最后用全新客户端回退共享，并记录返回码。

> 为什么不往网易云目录放 DLL？部分发行版（如联想商店封装）带完整性校验，目录里出现外来 DLL 会直接拒绝启动。注入方式不修改网易云安装目录。
>
> 参考实现：[AMExclusive](https://github.com/AntiOblivionis/AMExclusive)（为 Apple Music Windows 版提供 WASAPI 独占输出，MIT）。

## 快速开始（普通用户）

1. 双击 `安装-开启独占模式.bat`（**不需要管理员**）。
   - 批处理只调用原生 `NCMExTray.exe --install`，不执行安装 PowerShell。安装会关闭旧托盘和网易云，把组件装到 `%LOCALAPPDATA%\NCMExclusive\bin\`，写入当前用户 `Run` 开机启动项，并把旧日志保存为 `log_previous.txt`。
2. 重新打开网易云音乐，正常播放任意歌曲。
   - 独占流建立时会弹托盘气泡「WASAPI 独占模式已生效」。
3. 单击托盘图标可切换独占开关（绿=开，灰=关），并自动重启网易云使设置生效。**图标只表示开关状态，不代表独占已经成功**。
   - 托盘需要保持运行；右键菜单可停/启注入、重启网易云、打开日志。

### 验证独占是否生效

- 查看 `%APPDATA%\NCMExclusive\log.txt`，必须出现 `独占模式已生效`；出现 `共享回退`、`Initialize 直通` 或完全没有 `Client_Initialize` 都不算成功。
- 新日志应包含 `build=20261024-fix12-toggle`。诊断脚本会对比实际 DLL 与交付 DLL 的 SHA-256，排除误用旧版。
- 在同一输出设备上，独占生效后其他程序不应继续通过共享混音发声。测试时先让网易云独占播放，再启动 B 站等其他播放器；若它们改用其他输出设备，则此测试无效。
- 要验证 Bit-Perfect，还需关闭网易云音效并核对源格式、日志格式和 DAC 面板采样率，不能仅凭“独占”下结论。

## 文件清单

| 文件 | 说明 |
|---|---|
| `安装-开启独占模式.bat` | 双击运行（免管理员），装托盘+注入组件并开机自启 |
| `卸载-恢复默认.bat` | 双击运行（免管理员），删除托盘与注入组件 |
| `dist\NCMExTray.exe` | 托盘：一键开关独占 / 控制定向注入 / 重启网易云 |
| `dist\ncmex_inject.dll` | 注入载荷（x64），仅由托盘定向送入网易云进程 |
| `dist\x86\ncmex_inject.dll` | 32 位注入载荷（备用） |
| `dist\x64\*.dll` `dist\x86\*.dll` | 13 种载体代理 DLL（高级：仅官方版网易云手动放置用） |
| `src\` | 全部 C++17 源码，零第三方库 |
| `诊断v2-注入检测.bat` | 显示实际 DLL 哈希、注入状态和新日志（诊断内容 v3） |
| `诊断-收集信息.bat` | 收集网易云目录、旧代理 DLL 残留等环境信息 |

安装后实际运行位置：`%LOCALAPPDATA%\NCMExclusive\bin\`；配置与日志在 `%APPDATA%\NCMExclusive\`。

## 配置文件

`%APPDATA%\NCMExclusive\config.ini`：

```ini
[exclusive]
enable=1        # 总开关：1 独占 / 0 原样共享（托盘实时改写此项）
pcm_fallback=1  # 设备不支持 float32 独占时，改 PCM32 独占并自动转换
balloon=1       # 首次生效弹托盘气泡
verbose=0       # 详细日志
```

## 常见问题

**1. 网易云启动报错“检测到系统环境问题，软件无法运行”？**
这是网易云的通用启动崩溃提示（[BetterNCM 也有相关案例](https://github.com/std-microblock/BetterNCM-Installer/issues/89)）。当前安装模式不向网易云目录写文件；若旧版留下过 `version.dll`、`msimg32.dll`，先运行 `卸载-恢复默认.bat`，并检查网易云目录没有这些残留。

**2. 播放卡死、崩溃或没声音怎么办？**
先运行 `卸载-恢复默认.bat`，再彻底退出并重开网易云；必要时重启电脑以卸载仍被其他进程占用的旧钩子 DLL。独占失败会尝试回退共享，但不同客户端版本和驱动仍可能不兼容，不能承诺绝对不影响播放。请把新日志和诊断结果发给开发者。

**3. 日志显示「独占不可用」或「共享回退」？**
常见原因：
- 声卡/驱动不支持请求的独占格式；
- 播放设备属性 → 高级中未允许应用程序独占控制；
- 其他程序已经独占该设备；
- USB DAC 不支持 float32 独占：保持 `pcm_fallback=1`，插件会尝试 PCM32 并做 float→int32 转换。
日志中的 HRESULT 返回码用于进一步定位，不能把共享回退当成独占成功。

**4. Microsoft Store/UWP 版能用吗？**
不支持。当前目标是普通 Win32 桌面进程；本机调试对象是 x64 联想商店封装版。

**5. 其他网易云版本都能用吗？**
不保证。不同版本可能改变音频栈或增加完整性保护；请先用诊断确认实际模块和初始化日志，不要只看托盘图标。

**6. 杀软报毒？**
远程线程、进程内 DLL 和目录代理加载都可能触发启发式拦截。定向注入减少了全局钩子的影响面，但不保证安全软件一定放行。本项目源码可审计，是否加入排除由你自行决定；不放心就不要使用。

**7. 独占模式下为什么其他程序没声音？**
这是独占同一音频设备的预期行为。单击托盘只改变开关；要释放已经建立的独占流，请停止播放或重启网易云。

**8. 安全软件提示“远程线程/注入”怎么办？**
托盘只对 `cloudmusic.exe` 调用 `CreateRemoteThread + LoadLibraryW`。可在托盘菜单停用定向注入，但已经注入的网易云要重启后才会完全卸载；下次启动前请确认托盘和注入均已开启。

**9. 托盘必须一直运行吗？**
是。托盘负责注入新启动的网易云进程。托盘退出后，已经注入的进程仍保留其当前行为，直到网易云重启。

## 自行编译

Windows 上双击 `build.bat`（需 VS2022 Build Tools 或 mingw-w64 g++），会编译 x64 主组件并生成 `NCMExclusive-win-x64.zip`。完整 x64/x86 与 13 种备用载体在 WSL 项目目录执行：

```bash
bash src/build_wsl.sh
bash src/build_wsl32.sh
```

交付前仍需在实际网易云版本和声卡上播放验证；编译成功不代表独占已经在你的设备上生效。
